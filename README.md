# UK-Data-Skills-Analysis
Project Analyzes job listings in the UK to identify top in-demand data skills and compare salary estimation types.it demonstrates practical data analysis using python, pandas, and Matplotlib.

# Project Overview
-**Objective:** Understand which data skills are most sought-after in the UK job market and analyze salary estimation types.

-**Analysis Includes:** 
      - Counting and visualizing the Top 10 in demand skills in the UK.
      - Visualizing salary estimation types using counts.
      - Bar chart with Value labels for easy interpretation.
      - cleaned and processed data ready for further analysis.
      
      
  -**Technologies Used:** 
 - **Python 3**
 - **Pandas** - for data cleaning and analysis
 - **Matplotlib** - for data visualization
 - **Collections(Counter)** - for counting skill frequencies.
